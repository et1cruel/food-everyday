# Master Prompt — FOOD EVERYDAY

คุณคือทีมออกแบบและพัฒนาเว็บสูตรอาหารภาษาไทย สร้าง FOOD EVERYDAY ให้คนทำอาหารที่บ้านเลือกมื้อถัดไปได้เร็วจากของที่มีในครัว และอ่านเรื่องราวของเมนูได้ในหน้าเดียว

## เนื้อหา

- เปิดด้วยเมนูสุขภาพที่คัดจากสูตรที่เน้นผัก ถั่ว ธัญพืชไม่ขัดสี หรือโปรตีนที่เหมาะกับสูตร พร้อมระบุวิธีปรับเครื่องปรุงหรือน้ำมันในแต่ละจาน ยึดหลักทั่วไปจาก WHO และคู่มืออาหารสำหรับคนไทยใน FAO หลีกเลี่ยงการอ้างสรรพคุณรักษาโรคและการใส่ตัวเลขโภชนาการที่ยังไม่ได้คำนวณ
- ทำคลังสูตรไทยทั้งส่วนกลางและภูมิภาค กับสูตรจากเอเชีย ยุโรป ตะวันออกกลาง แอฟริกา และอเมริกา ให้สลับระหว่างสุขภาพกับทุกเมนู แล้วกรองตามประเทศหรือวิธีปรุงได้ ครอบคลุมต้ม ผัด ทอด นึ่ง ย่าง/อบ และสลัด/ยำ
- แต่ละสูตรมีชื่อไทยและชื่อสากล ประเทศหรือภูมิภาค เวลารวม จำนวนที่ ขนาดวัตถุดิบ วิธีทำทีละขั้น และเรื่องราวของเมนู สำหรับสูตรดัดแปลงให้บอกว่าดัดแปลงจากอะไร ใช้แหล่งอ้างอิงที่เกี่ยวข้องตรงกับข้อความ เมื่อหลักฐานไม่ชัดเจนให้เล่าบริบทการกินแทนการเดาปีหรือผู้คิดค้น
- ใช้ภาพอาหารที่มีสิทธิ์ใช้งาน ระบุภาพสร้างด้วย AI ตามจริง สูตรที่ไม่มีภาพให้ใช้ภาพแทนตามหมวดโดยไม่ทำให้สับสนว่าเป็นรูปของจานนั้น

## ประสบการณ์ใช้งานและภาพลักษณ์

ใช้พื้นกระดาษ #f7f6ef สีเขียวสน #173c32 และเขียวใบอ่อน #dceda9 กับตัวอักษรไทยอ่านง่าย จัดหน้าคล้ายหนังสือสูตรอาหารร่วมสมัย ใช้ภาพต้มยำกุ้งเป็นจุดนำสายตาคู่พาดหัวภาษาไทย จากนั้นวางช่องค้นหา ตัวกรอง และรายการสูตรต่อกันทันที ให้ปุ่มอ่านสูตรและบันทึกกดง่ายทั้งเมาส์ คีย์บอร์ด และจอสัมผัส

ค้นได้จากชื่อไทย ชื่อสากล ประเทศ และวัตถุดิบ รองรับการรวมหลายตัวกรอง แสดงผลลัพธ์และสถานะเมื่อหาไม่พบ เปิดสูตรจากลิงก์โดยตรง บันทึกเมนูโปรดในเบราว์เซอร์ และติ๊กวัตถุดิบที่เตรียมแล้วได้ในหน้าสูตร

## การส่งมอบ

ใช้เว็บสแตติกที่รันด้วย Node.js สำหรับตรวจข้อมูลและทดลองเปิดหน้า เก็บไฟล์ที่ใช้เสิร์ฟเว็บใน public ตรวจความครบของสูตรและลิงก์รูป ทดสอบค้นหา ตัวกรอง เปิดสูตรโดยตรง บันทึกเมนูหลังรีโหลด และการจัดหน้าที่ขนาดมือถือ สร้าง GitHub repo ใหม่ภายใต้ et1cruel แล้ว push ไป main เผยแพร่ public ผ่าน Cloudflare Pages และตรวจจาก URL สาธารณะ
